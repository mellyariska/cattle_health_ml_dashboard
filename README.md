# 🐄 Cattle Health Monitoring & Machine Learning Dashboard

## Machine Learning-Based Forecasting System for Early Disease Detection in Beef Cattle Using IoT Sensor Data

Dashboard ini dikembangkan untuk memantau kondisi kesehatan sapi potong menggunakan data fisiologis, perilaku, konsumsi, dan lingkungan yang diperoleh dari sensor IoT.

Dashboard mengintegrasikan analisis data dan Machine Learning untuk membantu mendeteksi risiko penyakit sapi secara lebih dini.

---

# 1. Tujuan Dashboard

Dashboard dikembangkan untuk:

1. Memantau kondisi kesehatan setiap sapi secara individual.
2. Memantau data fisiologis sapi secara berkala.
3. Memantau kondisi lingkungan kandang.
4. Menganalisis hubungan antara faktor fisiologis dan lingkungan.
5. Mengidentifikasi sapi yang memiliki risiko penyakit.
6. Menghasilkan Disease Risk Score.
7. Menghasilkan Disease Alert.
8. Menampilkan feature importance dari model Machine Learning.
9. Mendukung sistem peringatan dini penyakit pada sapi.
